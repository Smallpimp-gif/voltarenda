# Бот напоминаний об оплате — Вольтаренда

Telegram-бот, который напоминает арендаторам о недельном платеже за
велосипед. Список арендаторов берётся из таблицы «Платежи арендаторов»,
даты платежей считаются автоматически (каждые 7 дней от даты заезда).

## Как это устроено

- **Long polling**, а не webhook. Бот сам опрашивает Telegram (исходящее
  соединение). Это важно: хостинг сайта за фильтром, который режет
  входящие запросы из-за рубежа (в т.ч. от серверов Telegram и GitHub),
  но исходящие к Telegram работают — `lib/notify.ts` уже так шлёт.
- Поэтому бот должен **жить процессом на том же сервере, что и сайт**
  (где уже есть Node и доступ к Telegram). GitHub Actions/webhook тут
  не годятся.
- Бот — тот же `@Voltarenda`, что шлёт заявки. `getUpdates` (бот) и
  `sendMessage` (notify) на одном токене не конфликтуют.

## Важное ограничение Telegram

Бот **не может написать первым**. Пока арендатор сам не нажмёт «Старт»
в боте, у нас нет его `chat_id` и отправить ему ничего нельзя. Поэтому
каждый клиент один раз пишет боту, а оператор привязывает его к договору.

## Файлы

```
bot/index.mjs            — сам бот (запуск)
bot/lib/                 — расчёт дат, тексты, хранилище
bot/import-tenants.py    — Excel → data/bot/tenants.json
data/bot/tenants.json    — список арендаторов (НЕ в гите: PII)
data/bot/subscribers.json— привязки chat_id ↔ арендатор (НЕ в гите)
data/bot/sent-log.json   — что уже отправлено (НЕ в гите)
```
`data/` в `.gitignore` — данные арендаторов в публичный репозиторий не
попадают. **Бэкапь `data/bot/` отдельно** (там привязки клиентов).

## Настройка (один раз)

1. **Переменные окружения** в `.env` (или в systemd, см. ниже):
   ```
   TELEGRAM_BOT_TOKEN=...   # тот же, что у notify
   TELEGRAM_CHAT_ID=...      # chat_id оператора (см. шаг 2)
   ```
2. **Узнать свой chat_id:** запусти бота (шаг 4), напиши ему `/id` —
   он ответит числом. Впиши его в `TELEGRAM_CHAT_ID`, перезапусти.
   Без этого команды оператора и привязка кнопками не работают.
3. **Список арендаторов** уже сгенерён. После правок в Excel обнови:
   ```
   python3 bot/import-tenants.py "/путь/к/Платежи_арендаторов.xlsx"
   ```
   (берёт только строки со статусом «активен»; уже введённые username
   сохраняются).
4. **Запуск:**
   ```
   npm install
   npm run bot
   ```
   В консоли: `@Voltarenda на связи (long polling)`.

## Как подключается арендатор

1. Клиент открывает `t.me/Voltarenda`, жмёт **Старт**.
2. Оператору падает сообщение: «Новый пользователь… Кто это?» со
   списком фамилий-кнопок.
3. Оператор жмёт нужную фамилию — клиент привязан, ему уходит
   подтверждение. Дальше идут напоминания.

Хочешь без кнопки? Впиши заранее в `data/bot/tenants.json` поле
`telegramUsername` (например `"ivan_petrov"`) — тогда при «Старте» бот
привяжет клиента сам.

## Команды

**Арендатор:** `/start` — подключиться · `/status` — ближайший платёж ·
`/stop` — пауза · `/resume` — снова включить.

**Оператор** (только из чата `TELEGRAM_CHAT_ID`): `/list` — все
арендаторы, кто подключён, даты · `/sendnow` — прогнать рассылку сейчас
(тест) · `/id` — свой chat_id.

## Расписание

Каждый день в **10:00 МСК** бот проверяет, у кого платёж **за 2 дня,
за день или сегодня**, и шлёт напоминание (один раз на каждый случай).
Поменять — `BOT_REMINDER_CRON` / `BOT_TZ` в `.env`.

## Держать живым на сервере

**systemd** (рекомендуется) — готовый юнит `bot/voltarenda-bot.service`:
```
sudo cp bot/voltarenda-bot.service /etc/systemd/system/
sudo nano /etc/systemd/system/voltarenda-bot.service   # поправь пути/User
sudo systemctl daemon-reload
sudo systemctl enable --now voltarenda-bot
sudo systemctl status voltarenda-bot
journalctl -u voltarenda-bot -f       # логи
```

**pm2** (если уже используется для сайта):
```
pm2 start npm --name voltarenda-bot -- run bot
pm2 save
```

## Если что-то не так

- `409 Conflict` при старте — где-то ещё запущен этот же бот или висит
  webhook. Закрой второй экземпляр; бот сам снимает webhook при старте.
- Напоминания не идут — проверь `npm run bot` в консоли на ошибки,
  затем `/sendnow` от оператора. Убедись, что у клиента нажат «Старт» и
  он привязан (`/list`).
- Клиент заблокировал бота — он автоматически уходит в паузу (`🔕`).
